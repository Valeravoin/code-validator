# Code Validator

Консольная утилита на Python для валидации кодов по правилам, сбора статистики и генерации «идеального» кода.

## Что делает

- Проверяет коды: длина 4–12 символов, нет пробелов, не начинается и не заканчивается на `_`, есть хотя бы одна цифра.
- Считает статистику: количество валидных, процент, мин/макс/среднюю длину.
- Суммирует все цифры и считает квадратный корень из суммы.
- Генерирует «идеальный» код на основе самого длинного валидного кода.
